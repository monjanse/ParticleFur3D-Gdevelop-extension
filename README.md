# Particle Fur 3D v1.7.1

Particle Fur 3D adds memory-efficient, GPU-skinned outer coat and
undercoat to animated GDevelop 3D models. includes a blender-adon to export the vertex groups to use in Gdevelop. the particlefur is viewable in game preview.

## Main features

- GPU skinning using the source model's skeleton and bind matrix.
- Indexed ribbon geometry for reduced memory use.
- Separate outer coat and undercoat.
- Coverage vertex-group masks.
- Regional density for tail, legs, paws, and ears.
- Optional long-coat mask with hanging and traveling-wave motion.
- Model texture color sampling.
- Automatic strand and memory budgets.
- Runtime regenerate/remove actions and status expressions.
